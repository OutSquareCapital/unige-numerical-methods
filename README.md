# numerical methods course repo

## Installation

Once the repo is cloned into your local machine, and you have ensured that you have `uv` installed, run the following two commands to finalize the setup and open the notebooks in your browser:

- `uv sync` to install the dependencies
- `uv run marimo edit <notebook>` to open the notebook in your browser
